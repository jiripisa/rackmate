# Rackmate 0.2.0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Rename Pluginarium to Rackmate and rebuild the mixer as the rack from `ui-prototype/`, with effects that switch on and off and move by dragging.

**Architecture:** Logic goes into `RackmateCore`, test first. An effect that is off stays hosted and only leaves the graph, so `CRenderCore` does not change. The SwiftUI layer stays thin and follows the prototype.

**Tech Stack:** Swift 6, SwiftPM, SwiftUI, Swift Testing, macOS 15, Sparkle.

**Spec:** `docs/superpowers/specs/2026-11-01-rackmate-design.md`, with `docs/superpowers/specs/2026-10-31-pluginarium-design.md` behind it. Visual reference: `ui-prototype/index.html`.

## Global Constraints

- SwiftPM and shell scripts only; never an Xcode project.
- New logic in `Sources/RackmateCore`, test first. `Sources/Rackmate` stays a thin layer.
- Every rule under "Rules that are easy to break" in `CLAUDE.md` binds: AU lifecycle on the main thread, the render thread never allocates, locks, logs or calls Swift, a nil `audioDeviceUID` never writes.
- Check the look with `CFFIXED_USER_HOME=<scratch dir>`, never the real home. No notes, no MIDI, no device picked, no standalone effect, no third-party plugin window. Capture with `screencapture -l <id>`, never the whole screen.
- Launch test instances from the shell: `open` brings the macOS microphone prompt back after each rebuild. Never answer that prompt.
- Every user-visible change gets a line under `## Unreleased` in `CHANGELOG.md`.
- Run `git status` before each commit and stage by name. No AI attribution. Do not push.
- `swift test` passes before every commit: 202 + 386 tests at the start, more as tasks add them.

## Review Focus

- A rack saved by 0.1.0 has no on/off field: every effect reads as on. Pinned in Task 2.
- Dragging the last effect out of a parallel stage, onto itself, or into a full stage. Pinned in Task 2.
- An existing Rackmate folder must never be overwritten by the old one on a later launch. Pinned in Task 1.
- An effect turned off, moved to another channel and turned on again keeps its `HostedPlugin`. Pinned in Task 3.
- Meter order after an off effect leaves a chain: strips must still match channels. Pinned in Task 3.
